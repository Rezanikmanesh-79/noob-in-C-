# Noob in C++

🧠 My first steps into the world of C++ programming!

This repository contains my early exercises and practice projects while learning C++. It's a collection of simple programs that helped me understand the basics of:

- Variables and Data Types
- Conditionals (if, else)
- Loops (for, while)
- Functions
- Arrays and Strings
- Pointers and References
- Object-Oriented Programming (Classes, Inheritance, etc.)

---

## 📂 Folder: `c++/`

All the C++ source files are inside the `c++/` folder. Each `.cpp` file is an individual small program focusing on a single concept or practice.

---

## ⚙️ How to Run

You can compile and run the `.cpp` files using g++ (Linux/Mac) or any C++ compiler of your choice.

Example:

```bash
g++ filename.cpp -o output
./output
